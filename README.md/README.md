# A Re Ageng Social Services Website

## Project Overview

This project is a proposed website for **A Re Ageng Social Services**, a community-focused organisation based in South Africa.

The purpose of the website is to provide an easy-to-use online platform where visitors can learn about the organisation, its services, community programmes and ways to make enquiries.

This website was developed as part of an academic web development project.


## Website Pages

The website consists of six main pages:

### 1. Home

The Home page introduces visitors to A Re Ageng Social Services and provides an overview of the organisation and its purpose.

### 2. About Us

The About Us page provides information about the organisation, including its proposed mission, vision and values.


### 3. Programmes

The Programmes page provides information about proposed community awareness, youth development, family support, community outreach and volunteer initiatives.

### 4. Enquiry

The Enquiry page contains a form that allows visitors to provide their details and submit an enquiry.

### 5. Contact

The Contact page provides general organisation information, contact details, office hours and a contact form.
